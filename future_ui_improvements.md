# Future UI Improvements: Experience Section

## Objective
Elevate the visual design of the "Journey" (Timeline) section so that it matches the premium, glassmorphism aesthetic of the "Education" section. 

## Details
Currently, the Education cards use a rich aesthetic with backdrop blurs, gradients, and large background icons. The Journey section uses a minimal vertical timeline. 

To create better visual balance, we intend to:
1. **Interactive Cards:** Wrap each timeline item in a subtle, interactive card (similar to `Card` components).
2. **Hover States:** Add micro-interactions and glow effects to the timeline dots when hovering over the corresponding role.
3. **Consistent Styling:** Incorporate subtle background gradients or borders to the timeline items to align them with the polished look of the rest of the site.
